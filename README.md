# CivicPulse – AI-Powered Smart City Issue Reporter & Health Visualizer

## Overview

CivicPulse is an AI-powered Smart City web application designed to bridge the gap between citizens and municipal authorities. It enables users to report civic issues such as potholes, flooding, broken streetlights, garbage accumulation, and water leakage through an intuitive interface. The platform provides interactive maps, heatmap visualization, AI-powered issue categorization, and an officials dashboard to support faster and more transparent issue resolution.

## How It Works

1. Citizens report civic issues.
2. Issues are geo-tagged on the map.
3. AI categorizes and prioritizes complaints.
4. Complaints appear on the officials dashboard.
5. Municipal authorities review and resolve issues.
6. Resolution status is updated for citizens.
